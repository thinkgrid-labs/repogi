# Supported languages

Repogi indexes TypeScript (`.ts`) and TSX (`.tsx`). JavaScript, JSX, `.mts`, `.cts`, Rust and other languages are outside current indexing scope. Use native search for unsupported files. See [grammar limitations](TYPESCRIPT_GRAMMAR_LIMITATIONS.md) and [semantic scope](SEMANTICS.md).

Markdown (`.md` and `.markdown`, case-insensitive) is indexed separately as project knowledge. It supplies document intent and source locations, never resolved code relationships. See [Knowledge](KNOWLEDGE.md).
